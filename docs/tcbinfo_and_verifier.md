# TCBInfo and DCAP Verifier Contracts

> **OUTDATED**: Quartz no longer uses on-chain `tcbinfo` or `dcap-verifier`
> contracts. Attestation verification is now done via **zkdcap Noir/UltraHonk
> proofs** verified through the **Xion ZK module** (`ProofVerifyUltraHonk`,
> direct gRPC query). This document is retained for historical reference only.
