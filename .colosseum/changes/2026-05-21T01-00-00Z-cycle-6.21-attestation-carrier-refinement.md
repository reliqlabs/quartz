## Honesty caveat (carried from cycle 6.18)

`UserDataCommit` structure containing infinite-cardinality fields
(`domainSep : List UInt8`, `contractAddr : String`), the
`commitHashE : UserDataCommit ↪ BitVec 512` axiom is now type-level
visibly pigeonhole-impossible. Similarly `commitHashBytesE` over
`ByteSeq = List UInt8 ↪ BitVec 512`. No existing proof derives
`False` from this, but the impossibility is structurally exposed.
The substantive Option-(a) closure (replace these axioms with
random-oracle handlers backed by VCV-io's `randomOracle` +
birthday bound) is now mechanically tractable — both `Fintype`
constraints (codomain `Fintype` and `DecidableEq` on the index
type) are now satisfied. Queued as cycle 6.22.
