## Analysis

The classical `session_confidentiality_via_extractor` proof at `Confidentiality.lean:75-84` witnesses the `∃ pk, ...` conclusion with `pk := c.eciesPubkey`:

- `pkOfUserData h.msgUserData = some c.eciesPubkey` holds via `pkOfUserData_commitHash` after rewriting via `h_commit`.
- `decrypt sk (encrypt c.eciesPubkey msg) = some msg` holds via `roundtrip` after rewriting via `h_sk` (transitively, through `session_confidentiality`).

Both conjuncts are unconditional theorems given the hypotheses. The failure event "hypotheses hold but no witness `pk` exists" is **provably impossible**: every adversary input that satisfies the hypotheses can be witnessed with `pk = c.eciesPubkey`.

`extFailAdv 𝒜 n = Pr[winPred | 𝒜 n] = 0` for all `𝒜` and `n`. The lift requires no parametric hypothesis.
