## Motivation

Round A adversarial review (`.colosseum/attacks/lean-negl-lifts-2026-05-14/`) established that the prior form of `verifyGroth16_yields_decoded_negl` was structurally content-free: every probability-valued argument was a free function symbol, the bound was an assumed hypothesis, and the proof reduced to `negligible_of_le` (a closure property of `negligible`). Cycle 6.4 is the pattern-establishing fix.

## Changes

### Added — content-bearing predicates and advantages

In `ProtocolVCVio.lean`, after the `Groth16SoundAdvantage` Type-alias (retained for downstream lifts):

```lean
def groth16SoundnessWinPred (p : Groth16Proof × PublicInputs) : Prop :=
  verifyGroth16 zkdcapVKey p.1 p.2 = true ∧
  ¬ was_signed_by_dstack (inputs_to_quote p.2)

def verifyGroth16FailPred (p : Groth16Proof × PublicInputs) : Prop :=
  verifyGroth16 zkdcapVKey p.1 p.2 = true ∧
  ¬ ∃ mr ud, verifyTdxQuote (inputs_to_quote p.2) = some (mr, ud)

noncomputable def groth16SoundnessAdv (𝒜 : Groth16SoundAdv) (n : ℕ) : ℝ≥0∞ :=
  Pr[ groth16SoundnessWinPred | 𝒜 n ]

noncomputable def verifyGroth16FailAdv (𝒜 : Groth16SoundAdv) (n : ℕ) : ℝ≥0∞ :=
  Pr[ verifyGroth16FailPred | 𝒜 n ]

theorem verifyGroth16FailPred_imp_groth16SoundnessWinPred
    (p : Groth16Proof × PublicInputs)
    (h : verifyGroth16FailPred p) : groth16SoundnessWinPred p :=
  ⟨h.1, fun h_signed => h.2 (verifyTdxQuote_complete _ h_signed)⟩
```

### Replaced — the lift theorem itself

Was (5 params, including free `protocolFailAdv` and assumed `h_bound`):
```lean
theorem verifyGroth16_yields_decoded_negl
    (𝒜 : Groth16SoundAdv) (adv : Groth16SoundAdvantage)
    (protocolFailAdv : Groth16SoundAdv → ℕ → ℝ≥0∞)
    (h_bound : ∀ n, protocolFailAdv 𝒜 n ≤ adv 𝒜 n)
    (h_negl : negligible (adv 𝒜)) :
    negligible (protocolFailAdv 𝒜) :=
  negligible_of_le h_bound h_negl
```

Now (2 params; bound is proven internally):
```lean
theorem verifyGroth16_yields_decoded_negl
    (𝒜 : Groth16SoundAdv)
    (h_negl : negligible (groth16SoundnessAdv 𝒜)) :
    negligible (verifyGroth16FailAdv 𝒜) := by
  refine negligible_of_le ?_ h_negl
  intro n
  exact probEvent_mono (fun p _ hp =>
    verifyGroth16FailPred_imp_groth16SoundnessWinPred p hp)
```

## What Round A attacks this addresses (for this lift only)

- **Attack #1 (Triviality / free-symbol tautology)**: structurally closed. `verifyGroth16FailAdv` is now a `def`. The user cannot instantiate it to `fun _ _ => 0` — it has a fixed body. Verified via `#print verifyGroth16FailAdv`: `fun 𝒜 n => probEvent (𝒜 n) verifyGroth16FailPred`.
- **Attack #2 (Trojan-horse `h_bound`)**: structurally closed. The `h_bound` parameter is gone; the pointwise bound is proven by `probEvent_mono` + `verifyGroth16FailPred_imp_groth16SoundnessWinPred`. There is no longer a place for the user to smuggle in `negligible f → negligible f`.
- **Attack #11 (over-quantified `protocolFailAdv` signature)**: structurally closed. `verifyGroth16FailAdv` is a top-level `def` of type `Groth16SoundAdv → ℕ → ℝ≥0∞`; the theorem no longer takes a free function symbol.

The `groth16Verifier` bundle axiom appears in the closure because `verifyGroth16` and `zkdcapVKey` (used in the win predicate) are derived from it — i.e. the *verifier itself* is part of the substrate the security claim is over. The bundle's *soundness projection* (`groth16Verifier.sound`) is NOT in the closure, because it is shadowed by `h_negl : negligible (groth16SoundnessAdv 𝒜)` — exactly the Round A reviewer-checklist reframing ("each `_negl` closure contains exactly the axioms the `_classical` form contains, minus the bundle axiom **projection** shadowed by the parametric negligibility hypothesis").
